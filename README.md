# CAD Drafter — Blenderで縮尺どおりの図面を作るアドオン

BlenderをCADのように使い、**縮尺（1:100など）に合わせた図面**を作成・出力するためのアドオンです。

## 設計コンセプト

CADの「モデル空間／ペーパー空間」の考え方をBlenderに持ち込みます。

- **モデルは常に実寸で作図する**（Blenderの1単位 = 1m）。部屋の幅が3640mmなら、3.64mでモデリングする。
- **縮尺は出力時にだけ適用する**。1:100でA3に出すなら、A3用紙（420×297mm）がカバーする実空間は 42m × 29.7m。この範囲を示す「用紙枠」をワールドに置き、その中に収まるように作図する。
- 寸法線・文字・線幅は「**印刷したときのサイズ（mm）**」で指定する。文字高さ3mmと指定すれば、1:100でも1:50でも、印刷物の上では常に3mmになる。

この方式により、モデルの寸法をいじらずに縮尺だけ差し替えられます（1:100 → 1:50 への変更は設定を変えて用紙枠・カメラ・寸法線を作り直すだけ）。

## 機能（v0.1）

| 機能 | 内容 |
|---|---|
| 縮尺・用紙設定 | 1:1〜1:500のJIS標準縮尺＋カスタム、A4〜A0・縦横 |
| 用紙枠の作成 | 縮尺どおりの実空間サイズの枠を原点に配置。単位(mm表示)・スナップ・グリッド(紙面10mm相当)も自動設定 |
| 図面カメラ | 用紙枠にぴったり一致する平行投影カメラ＋DPI指定の印刷解像度を自動設定。レンダリングすればそのまま縮尺どおりの図面画像になる |
| 精密作図 | 3Dカーソル基準で長さ・角度を数値入力して線分／矩形を作成（実寸入力） |
| 寸法線 | 編集モードで2頂点を選んで追加。JIS建築風（引出線＋チック＋上付き文字）。寸法値は実寸mm |
| 寸法の再構築 | 縮尺や文字高さを変えた後、既存の寸法線すべてに反映 |
| DXF出力 | 可視メッシュの辺を真上から投影し、**DXF R12**として出力。AutoCAD / Jw_cad / LibreCAD / QCADでそのまま開ける。実寸／紙面寸法を選択可 |
| SVG出力 | 同じ投影を**紙面mm単位の正確なSVG**として出力。図枠・縮尺表記付き。Inkscape等で開ける |

## インストール

1. このリポジトリの `cad_drafter` フォルダをzipにする：
   ```
   zip -r cad_drafter.zip cad_drafter
   ```
2. Blenderの `編集 > プリファレンス > アドオン > インストール` で zip を選択
3. 「CAD Drafter」を有効化
4. 3Dビューポートのサイドバー（Nキー）に「CAD」タブが現れます

対応バージョン: Blender 3.0以降（4.x含む）

## 使い方（例: 1:100 でA3横の平面図）

1. **CADタブ**で縮尺 `1:100`、用紙 `A3`、横置き を選択
2. **「用紙枠を作成」** — 原点に 42m × 29.7m の枠ができ、単位がmm表示、スナップとグリッドがセットされる
3. 枠の中に実寸でモデリング／作図する
   - 「線分を作図」「矩形を作図」で数値入力（例: 幅 7280mm × 奥行 3640mm の矩形）
   - 通常のBlenderモデリングツールもそのまま使える（上から見たアウトラインが図面になる）
4. **寸法を入れる** — 対象メッシュの編集モードで2頂点を選択し「寸法線を追加」。F9のリドゥパネルでオフセットや配置側を調整
5. **出力**
   - CADデータ: 「DXFで図面を出力」。CADソフトでそのまま開いて編集・印刷できる
   - 画像: 「図面カメラを設定」→ レンダリング（F12）。300dpiならA3で4961×3508px、原寸印刷すれば縮尺どおり
   - ベクター: 「SVGで図面を出力」。紙面mm単位の正確なSVGが書き出される

## DXF出力の仕組み

### 線の出力方法

1. 対象オブジェクト（可視 or 選択メッシュ）の**評価済みメッシュ**（モディファイア適用後）を取得
2. 各**辺（edge）の2頂点**をワールド座標に変換し、XY平面に投影（真上から見た平面図）
3. 単位変換して **1辺 = 1本のLINEエンティティ** としてENTITIESセクションに書き出す

DXFは「グループコード＋値」のペアを並べたテキスト形式で、線1本は次のように書かれる：

```
0
LINE        ← エンティティ種別
8
OUTLINE     ← レイヤー名
10
0.0         ← 始点X (mm)
20
0.0         ← 始点Y
11
3640.0      ← 終点X
21
0.0         ← 終点Y
```

DXFはY軸が上向き（Blenderワールドと同じ）なのでSVGと違いY反転は不要。寸法の数字はTEXTエンティティ（文字高さ・回転・中央揃え）として出力される。円や曲線も現状はメッシュの辺なので短いLINEの集まりになる（CIRCLE/ARC化はロードマップ参照）。

### 出力単位（エクスポート時に選択）

| モード | 内容 |
|---|---|
| 実寸 (mm)（デフォルト） | 1 DXF単位 = 実寸1mm。CADの流儀で、開いた側で寸法がそのまま測れる（3640mmの壁は3640単位）。文字高さは「紙面mm × 縮尺分母」になり、縮尺印刷時に指定サイズになる |
| 紙面寸法 (mm) | 縮尺適用後の印刷サイズで出力（SVG出力と同じ） |

### レイヤー構成

| レイヤー | 内容 | 色 |
|---|---|---|
| OUTLINE | 外形線（一般のメッシュの辺） | 白/黒 (7) |
| DIM | 寸法線・寸法文字 | 赤 (1) |
| FRAME | 用紙枠・縮尺表記 | 緑 (3) |

形式はDXF R12 (AC1009) ASCII。文字コード問題を避けるため出力はASCIIのみ（寸法値は数字なので問題なし）。

**動作確認の手順**: LibreCADやQCADで書き出したDXFを開き、距離測定ツールで既知の寸法（例: 3640mmの壁）を測って一致することを確認する。

## 設定項目

| 項目 | 意味 |
|---|---|
| 縮尺 / 縮尺分母 | 図面の縮尺 1:N |
| 用紙 / 横置き | 出力用紙サイズと向き |
| 文字高さ (mm) | 印刷時の寸法文字の高さ（JIS推奨: 2.5〜5mm） |
| 寸法線オフセット (mm) | 測定点から寸法線までの紙面上の距離 |
| 寸法の小数桁 | 寸法値(mm)の小数点以下桁数（建築は通常0） |
| 線幅 (mm) | SVGの外形線の太さ（寸法線はその半分） |
| DPI | レンダリング解像度 |

## 内部構成

```
cad_drafter/
  __init__.py     # bl_info・登録
  properties.py   # シーン設定（縮尺・用紙・文字/線サイズ）
  operators.py    # 用紙枠・カメラ・作図・寸法線
  dxf_writer.py   # DXF R12生成（bpy非依存の純関数）
  export_dxf.py   # DXFエクスポーター
  export_svg.py   # SVGエクスポーター
  ui.py           # サイドバーパネル
```

寸法線は測定点をカスタムプロパティ（`cad_p1` / `cad_p2` / `cad_offset_mm`）として保持しており、「寸法線を再構築」で現在の設定から再生成されます。用紙枠は `cad_sheet`、寸法線は `cad_dim` タグで識別され、SVG出力時に線の太さが切り替わります。
